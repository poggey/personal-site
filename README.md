# personal-site

Personal site for Padraig Middleton. Next.js (App Router), TypeScript and CSS Modules.

## Commands

| Command              | What it does                                                                |
| -------------------- | --------------------------------------------------------------------------- |
| `npm run dev`        | Local dev server at localhost:3000                                          |
| `npm run build`      | Production build                                                            |
| `npm run lint`       | ESLint                                                                      |
| `npm run format`     | Prettier                                                                    |
| `npm run test`       | Unit tests (Vitest)                                                         |
| `npm run e2e`        | End-to-end and accessibility tests (Playwright, at 375, 768 and 1440 wide)  |
| `npm run check:copy` | Fails on em dashes, en dashes used as dashes, and banned words in site copy |

Requires Node 24 or later (see `.nvmrc`).
